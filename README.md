# Team Collaboration Portal

## Project Description

This project is a Team Collaboration Portal designed to help users work together and manage their activities.

## Main Features

- User Sign-Up: Allows users to create an account.
- Task Management: Allows users to create, view, update and delete tasks.
- Document Sharing: Allows users to upload, view and share documents with team members.

## Technologies Used

- Git and GitHub for version control.
- Visual Studio Code for development.
- C# for feature implementation.
